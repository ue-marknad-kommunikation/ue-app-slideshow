Editor Shell

Flexibel applayout som kollapsar till en kolumn under 1100px. Alla varianter krymps här för demo.

1 kolumn (default)

.editor-shell – centrerad vy för enklare verktyg, formulär eller dashboards.

Huvudinnehåll

Formulär, dashboard eller annan vy

2 kolumner – sidebar vänster

.editor-shell.editor-shell--sidebar – navigation eller filter till vänster, innehåll till höger.

Sidebar

Navigation / filter

Huvudinnehåll

Redigeringsvy eller lista

2 kolumner – sidebar höger

.editor-shell.editor-shell--dual – innehåll till vänster, egenskaper eller detaljer till höger.

Huvudinnehåll

Editor eller preview

Egenskaper

Detaljer / inställningar

3 kolumner

.editor-shell.editor-shell--three – som blankettgeneratorn: kontroller, editor och egenskaper.

Vänster

Kontroller

Mittinnehåll

Preview / editor

Höger

Egenskaper

Anpassning

Anpassa sidokolumnens bredd och max-width med custom properties:

.editor-shell {
  --shell-sidebar: 280px;     /* sidokolumnens bredd */
  --shell-max-width: 1400px;  /* max-bredd på hela shellen */
}
